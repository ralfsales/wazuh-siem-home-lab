# Wazuh SIEM Lab

## Project Overview

This project demonstrates the deployment and operation of a Security
Information and Event Management (SIEM) environment using Wazuh and
Ubuntu virtual machines running in Oracle VirtualBox.

The objective was to simulate a Security Operations Center (SOC)
workflow by deploying a centralized Wazuh server, enrolling endpoints,
collecting logs, generating security events, and performing threat
hunting activities.

------------------------------------------------------------------------

## Lab Architecture

**Wazuh Server** - Ubuntu 22.04 LTS - Wazuh Manager - Wazuh Dashboard -
Wazuh Indexer

**Endpoint** - Ubuntu 22.04 LTS - Wazuh Agent

**Network** - VirtualBox Host-Only Network - Wazuh Server:
192.168.56.108 - Ubuntu Agent: 192.168.56.107

## Security Events Generated

### User Creation Detection

Generated a new user account:

``` bash
sudo useradd hackerA
```

Observed Wazuh alert: - New user added to the system - Username
detected - User ID and Group ID recorded - Event successfully indexed
and searchable

### Authentication Failure Detection

Generated failed authentication attempts:

``` bash
sudo -k
sudo ls
```

Entered incorrect credentials to trigger authentication failures.

Observed Wazuh alert: - PAM User login failed - Source endpoint
identified - User and session information captured

### Package Installation Monitoring

Observed package installation events generated by Ubuntu package
management:

-   New Debian package installed
-   Package configuration changes
-   System software inventory updates
